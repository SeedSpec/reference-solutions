# Reference solutions in SeedSpec 0.2

The seven distributable reference packages use Protocol `0.2` and the
coordinated first-party reference version `0.2.0`.

The `authoring/` directories preserve review records created against the `0.1`
design previews. Their tool versions, package versions, protocol versions, and
digests are historical evidence and have not been rewritten. They do not
satisfy a current `seedspec publish-check`.

Before treating a reference seed as a marketplace publication, start a new
0.2 review workspace:

```bash
npx --yes @seedspec/cli@0.2.2 prepare <package-path> \
  --state <new-authoring-state>
```

This separation lets the repository validate the migrated package bytes without
pretending that an earlier review examined different bytes.
