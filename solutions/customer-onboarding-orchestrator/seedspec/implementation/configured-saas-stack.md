# Configured existing SaaS stack

Prefer this profile when the organization's approved systems can collectively
represent one stable case, milestone ownership, blockers, customer-visible
updates, attribution, and completion evidence without misleading duplication.

The implementing agent should identify the system of record for case identity,
map every required milestone and state, verify role and field visibility,
exercise retry behavior, and document which system owns timers and delivery
evidence. A collection of disconnected tasks is not sufficient merely because
every required label appears somewhere.
