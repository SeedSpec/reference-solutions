# Customer Onboarding Orchestrator

This reference workflow package turns an approved customer handoff into a
visible, owned onboarding plan across the organization's existing systems. It
preserves one core outcome while offering three implementation profiles:
configure the current SaaS stack, use an approved automation platform, or
operate a dedicated coordination service.

It has no committed realization yet.

```bash
npx @seedspec/cli validate solutions/customer-onboarding-orchestrator/seedspec
npx @seedspec/cli lint solutions/customer-onboarding-orchestrator/seedspec
npx @seedspec/cli begin solutions/customer-onboarding-orchestrator/seedspec
```
