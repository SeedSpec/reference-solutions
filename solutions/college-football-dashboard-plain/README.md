# College Football Dashboard — intent-only comparison package

This package is one half of a controlled implementation comparison. It contains
the same product definition, configuration, capability contract, and acceptance
criteria as `college-football-dashboard-andromeda`, but it does not include the
Andromeda source set or the Andromeda implementation skill.

It does include one optional Context7 instruction resource so both comparison
packages give an agent the same opportunity to retrieve current, version-aware
documentation for whatever stack the actual project uses.

```bash
npx @seedspec/cli validate solutions/college-football-dashboard-plain/seedspec
npx @seedspec/cli begin solutions/college-football-dashboard-plain/seedspec
```
