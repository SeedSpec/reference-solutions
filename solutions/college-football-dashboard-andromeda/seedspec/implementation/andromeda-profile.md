# Andromeda reference implementation profile

This profile recommends the preserved public AI Canvas Andromeda v1 source as
the dashboard's visual realization. It does not make Andromeda product intent.
The user may select `independent-web` instead, and the implementing agent should
recommend that alternative when the actual project has a governing visual
system or incompatible stack.

When selected:

1. Resolve and explicitly consult the
   `org.seedspec.guidance.andromeda-college-football-dashboard` skill.
2. Locate the preserved `reference` component through the resolved component
   index rather than assuming source-package paths.
3. Reuse only the components needed for the implemented surfaces.
4. Keep the dashboard's data-trust, status, source, freshness, accessibility,
   and responsive requirements authoritative over aesthetic rules.
5. Record material source changes and any declined Andromeda rules in project
   implementation notes.

The bundled source is a reference subset, not a complete application scaffold.
The agent remains responsible for application architecture, data integration,
tests, and verification.
