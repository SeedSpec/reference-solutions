# Operations Dashboard Starter Kit

This reference application package describes a reusable internal operations
console. Teams configure their record vocabulary, statuses, metrics, freshness
expectations, permissions, actions, and exports while retaining observable
rules for trustworthy internal software.

The included example configures a returns-operations dashboard. A realization
may adapt the interaction and technical architecture to its environment. It has
no committed realization yet.

```bash
npx @seedspec/cli validate solutions/operations-dashboard-starter/seedspec
npx @seedspec/cli lint solutions/operations-dashboard-starter/seedspec
npx @seedspec/cli begin solutions/operations-dashboard-starter/seedspec
```
