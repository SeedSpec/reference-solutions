# `org.seedspec.examples.family-coordination` 1.0.0

A provider supplies one household-scoped view of shared events and assigned
tasks. Consumers may rely on stable household membership, role-aware access,
attributed changes, timezone-correct schedules, and independently completable
task assignments.

The capability preserves event and task history when members leave and blocks
cross-household access. Allowance and meal-planning behavior is available only
when the corresponding package configuration is enabled; consumers must not
assume either optional module is present.
